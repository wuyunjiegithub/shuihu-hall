本项目使用 ES 模块与外置卡图，浏览器不允许从 file:// 直接加载。

请在项目目录执行下面任意一条命令，再访问 http://localhost:8000

python serve.py
python -m http.server 8000
npx serve .

（Windows 也可直接双击 serve.bat）
