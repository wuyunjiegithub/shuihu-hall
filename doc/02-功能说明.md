# 功能说明

> 面向使用者的功能清单。运行方式、目录结构见 [../README.md](../README.md)，设计背景见 [01-设计文档.md](01-设计文档.md)。

---

## 一、卡牌

- **收藏规模**：108 位梁山好汉（三十六天罡 + 七十二地煞）+ 六大恶人，共 114 张。
- **单张实体卡**：每张卡是一个有厚度的立方体，正面、背面分别是独立贴图，不是两幅图平铺。右键翻面看到的是这张卡的**背面**（翻过去后文字正向可读）。
- **原图中分裁剪**：英雄卡与恶人卡的素材都是「人物面 + 卡背面」左右拼接的原图，运行时裁成两半——左半只取人物面作正面，右半作卡背，因此卡面永远只显示一个人物，不会两个面挤在一张卡上。
- **金框**：正反面统一叠加程序化绘制的金色边框，还原实体卡的镶边质感。
- **悬浮名牌**：每张卡上方飘着姓名牌，显示编号、绰号与姓名（如 `001 及时雨·宋江`）；天罡为金色、地煞为淡蓝、恶人为红色。
- **光晕**：卡片自带柔光，天罡暖金、地煞幽蓝、恶人暗红；翻面时自动压暗，避免冲淡背面文字。

## 二、三种展厅布局

按键盘 `1 / 2 / 3` 或点击顶部布局条切换，切换时相机巡航路线随之改变，并自动来一次洗牌特效。

| 键 | 布局 | 形态 | 提示语 |
| --- | --- | --- | --- |
| `1` | 天罡地煞双星环 | 36 天罡悬于上空、72 地煞铺于下方，双层同心环反向旋转 | 天罡悬于天 · 地煞铺于地 |
| `2` | 悬浮岛屿 | 108 将分坐 6 座浮空岛，岛屿环列并上下起伏 | 水泊梁山 · 六岛聚义 |
| `3` | 悬浮长廊 | 卡片沿螺旋坡道盘旋上行，形成一条登堂长廊 | 螺旋上行 · 步步登堂 |

切换展厅或退出鉴赏时，所有卡片会**自动翻回正面**。

## 三、卡片工艺

顶部工艺条实时切换，切换只改卡面材质与光效，卡片本体与布局不变。

| 工艺 | 说明 |
| --- | --- |
| 普卡 | 哑光纸感，**不闪**，无镭射、无光晕 |
| 奖闪（镭射） | 硬闪镭射：随视角流动的彩虹条带 + 扫描线 + 金粉颗粒，配暖金光晕 |
| 冷烫 | 烫金烫银质感：冷色金属锐光，条带更宽、反射更硬，配冷蓝光晕 |
| 立绘 | 无框原画 + 极柔光晕（需额外扫描图，默认隐藏） |

镭射/冷烫使用**独立的全息箔卡背**（程序化生成），与普卡的「信息面卡背」区分开。

## 四、交互操作

**桌面端**

| 操作 | 效果 |
| --- | --- |
| 左键点击卡片 | 飞近鉴赏，打开详情面板 |
| 右键点击卡片 | 原地翻面看卡背 |
| 拖动空白处 | 环视整个展厅 |
| 左右拖动 | 卡片整体产生波动，随后自然衰减 |
| 滚轮 | 推进 / 拉远镜头 |
| 鉴赏中左右拖动 | 上一张 / 下一张 |
| `←` `→` | 鉴赏中切换上/下一张 |
| `1` `2` `3` | 切换三种展厅（恶人密室内无效） |
| `R` | 星穹洗牌 |
| `ESC` | 退出鉴赏 / 退出密室 |

**移动端 / 触屏**

| 操作 | 效果 |
| --- | --- |
| 单击卡片 | 鉴赏并查看详情 |
| 双击卡片 | 翻面看卡背 |
| 单指拖动 | 环视；鉴赏中左右滑动切换上一张 / 下一张 |
| 双指捏合 | 缩放镜头 |

## 五、星穹洗牌

全场重组特效，三种展厅与恶人密室通用，触发方式：按 `R`、点底部「✦ 洗牌重组」按钮、或切换展厅时自动播放一次。

分三个阶段：卡片向外**爆散**飞舞 → 空中**悬停自旋** → 逐张错峰**回落归位**，中心同时炸开一道冲击波光晕；每张卡带随机相位，落位与朝向精确回到原布局。

## 六、鉴赏面板

左键点开卡片后弹出，展示该人物的完整档案：

- 星位（天罡 / 地煞 / 恶人）
- 梁山排名与阵营说明（如「梁山第 001 位 · 三十六天罡」）
- 绰号、姓名（姓名逐字分开排版）
- 人物小传
- 卡背统一文案「—— 水浒英雄谱 · 统一小浣熊 1999 ——」
- 人物卡完整原图（左右两半即正反面，一眼看全；图下标注「左为正面 · 右为背面」）

鉴赏状态下卡片正对镜头、背景卡片后退虚化，可连续左右翻看。

## 七、恶人密室（彩蛋）

展厅中央的「替天行道」石碑上有一颗悬浮光球。**连续快速点击光球 3 次**（间隔不超过 2.2 秒）即解锁密室，随后右下角出现入口按钮。

密室是一个独立的下沉空间，六大恶人卡环绕陈列，灯色转为暗红；进入后同样支持点击鉴赏、翻面、洗牌，`ESC` 或按钮返回大厅。

密室只有这一种陈列，因此进入后顶部的「展厅」切换按钮会置灰锁定、`1/2/3` 快捷键也一并屏蔽，提示条改为「恶人密室 · 独立场景，返回主馆后可切换展厅」；返回主馆后恢复。

## 八、性能与兼容

- **自动降级**：移动端、窄屏（< 820px）或 CPU 逻辑核心 ≤ 4 时判定为低配，自动关闭抗锯齿、限制像素比到 1.5、停掉后处理泛光并减少背景星点数量。
- **贴图缓存**：所有卡图裁剪结果按 URL 缓存，切换工艺、反复进出鉴赏都不会重复解码。
- **加载屏**：首屏显示进度条，贴图就绪后淡出。
- 依赖 WebGL，需通过本地 HTTP 服务打开（ES 模块与外置贴图不允许 `file://` 直读）。

## 九、调试接口

页面运行时暴露 `window.__HALL`，可在控制台直接调用：

```js
__HALL.switchLayout('islands')   // 切换展厅
__HALL.switchCraft('standard')   // 切换工艺
__HALL.shuffle()                 // 洗牌
__HALL.unlockVault()             // 直接解锁密室
__HALL.enterVault() / exitVault()
__HALL.layout / __HALL.craft / __HALL.vault   // 当前状态
__HALL.heroCards / __HALL.villainCards        // 卡片对象
```
