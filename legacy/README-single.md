# 水滸英雄傳 · 星穹卡馆

一座用 Three.js 做的 3D 水浒卡陈列馆：108 位梁山好汉 + 6 大恶人，三种展厅布局可切换，四种卡面工艺可切换。

> ⚠️ **重要声明**：卡图与原画版权归**统一企业**所有。本项目为**个人非商用**的怀旧收藏与技术练习，**禁止部署到任何公网环境**，禁止用于商业用途。

---

## 一、怎么打开（三选一）

### 方式 A：单文件版（推荐，双击即开）

```
dist/shuihu-hall-single.html
```

双击用浏览器打开即可，**不需要装任何东西、不需要联网**。
这是内嵌了全部卡图与脚本的离线版本（约 13MB），可以拷到 U 盘、发给朋友。

> 单文件版功能：三种展厅布局可切换 + 普卡工艺 + 点击鉴赏 + 恶人密室。
> 因为体积考虑，单文件版只内嵌了「普卡」一套卡图，工艺切换里只有普卡。

### 方式 B：完整版（模块化源码，功能最全）

```bash
cd shuihu-hall
node tools/serve.js          # 启动本地服务（默认 8080 端口）
```

然后浏览器打开 `http://localhost:8080`。

完整版包含**四套卡图工艺**（普卡 / 奖闪镭射 / 冷烫 / 立绘），能体验镭射卡效果。

> 为什么完整版不能直接双击打开？浏览器在 `file://` 协议下会拦截网页加载本地图片作为 3D 贴图（跨域限制），所以需要一个本地服务。没有 Node 也可以用 `python3 -m http.server 8080` 代替。

### 方式 C：重新打包单文件版

```bash
node tools/build-single.js   # 产出 dist/shuihu-hall-single.html
```

## 二、操作方式

| 操作 | 桌面 | 手机 |
|---|---|---|
| 环视 | 移动鼠标 | 单指拖动 |
| 放大缩小 | 滚轮（浏览器缩放） | 双指缩放 |
| 鉴赏某张卡 | 点击卡牌 | 点击卡牌 |
| 返回巡览 | `ESC` 或点击空白处 | 点面板关闭按钮或空白处 |
| 换展厅 | 底部「展厅」按钮 / 键盘 `1` `2` `3` | 展开「展厅 / 工艺 ▾」菜单 |
| 换工艺 | 底部「工艺」按钮 | 同上 |
| 恶人密室 | 连点 3 次碑顶光球 → 点「进入恶人密室」 | 同左 |
| 离开密室 | `ESC` / 「返回主馆」 | 「返回主馆」 |

## 三、三种展厅

| 展厅 | 布局特征 | 意境 |
|---|---|---|
| **天罡地煞双星环**（默认） | 天罡 36 张悬于高空金色环，地煞 72 张铺在地面外环 | 天罡在天 · 地煞在地 |
| **悬浮岛屿** | 分作 6 座浮岛，每岛 18 张卡，岛高错落 | 水泊梁山 · 六岛聚义 |
| **悬浮长廊** | 108 张沿螺旋走廊单列上升，全部朝中轴 | 螺旋上行 · 步步登堂 |

切换时卡片会错峰飞向新位置，每个展厅有各自的镜头巡航路线。

## 四、四种卡面工艺

| 工艺 | 对应实物 | 特效 |
|---|---|---|
| **普卡** | 当年最常见的纸卡 | 哑光纸感 + 随视角缓慢流动的柔和光泽 |
| **奖闪（镭射）** | 硬闪卡（最稀有的一类） | 强镭射彩虹流光，转动视角时剧烈变化 |
| **冷烫** | 烫金/烫银工艺 | 冷色金属反光，边缘锐利 |
| **立绘** | 无框原画版 | 极柔光晕，突出画作本身 |

四种工艺共用一套参数化着色器，只是强度、配色、条纹密度不同。**普卡并非"无特效"**，而是低强度哑光版本。

---

## 五、恶人密室

1. 在主馆找到中央的**聚义碑**
2. 连点碑顶的**金色光球 3 次**（两次点击间隔需在 2.2 秒内）
3. 右下角出现「进入恶人密室」按钮 → 点击进入

密室在地下，配有暗红雾与血色光柱，6 张恶人卡（高俅、蔡京、童贯、西门庆、潘金莲、高衙内）呈扇形展墙，可点击鉴赏其身份与结局。

## 七、想改点什么

| 需求 | 改哪里 |
|---|---|
| 改人物资料 / 加人 | `src/data.js`（`CHARACTERS` 数组） |
| 调展厅尺寸（环半径、高度） | `src/layouts.js` 里各布局的 `place()` |
| 调工艺特效强度 | `src/cards.js` 的 `CRAFTS` 表（strength / fresnelPow / bandMix / stripe） |
| 调镜头巡航路线 | `src/layouts.js` 里各布局的 `cruise()` 控制点 |
| 换卡图 | 替换 `assets/<工艺>/<编号>.webp`（编号即梁山排名） |
| 调密室触发次数 | `src/main.js` 中 `OrbTrigger` 的 `count >= 3` |

改完刷新页面即可，`tools/serve.js` 已禁用缓存。

## 八、调试验收小工具

浏览器控制台可用 `__HALL` 对象：

```js
__HALL.layout              // 当前展厅
__HALL.craft               // 当前工艺
__HALL.switchLayout('islands')   // 切展厅：dualRing / islands / corridor
__HALL.switchCraft('flash_prize')// 切工艺：standard / flash_prize / code_perm / character_art
__HALL.unlockVault()       // 直接解锁恶人密室
__HALL.enterVault()        // 进入密室
__HALL.cardPos(1)          // 查看某张卡当前位置
```
