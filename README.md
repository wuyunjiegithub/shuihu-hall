# 水滸英雄傳 · 星穹卡馆

Three.js 打造的 3D 水浒卡馆：108 将 + 六大恶人，三种展厅布局、四类卡片工艺（程序化镭射/冷烫）、恶人密室彩蛋、星穹洗牌特效。本项目已从「单文件离线版」拆分为正式的静态项目结构。

## 运行

需要通过本地 HTTP 服务打开（ES 模块 + 外置贴图不允许 `file://` 直读）：

```bash
python serve.py          # → http://localhost:9000（自动打开浏览器）
python serve.py 9000     # 指定端口
```

Windows 也可直接双击 `serve.bat`。或使用任意静态服务器：`python -m http.server`、`npx serve .`

> 若默认端口被别的程序占用或被系统保护，脚本会**自动顺延到下一个可用端口**，并在窗口里打印实际地址（如 8001），按提示的网址访问即可。
> 启动后会自动用 **Chrome / Edge 以全屏方式**（F11 全屏）打开页面，按 F11 可退出全屏；找不到这两个浏览器时退回系统默认浏览器正常打开。加 `--no-browser` 参数则只起服务不打开页面。

> 若直接双击 `index.html`，页面会显示引导提示而非空白报错。

**完整功能清单（卡牌、三种展厅、四类工艺、交互操作、密室彩蛋）见 [doc/02-功能说明.md](doc/02-功能说明.md)。**

## 模块加载

`index.html` 先同步加载 `vendor/three.min.js`（提供全局 `THREE`），再以 `<script type="module">` 进入 `js/main.js`，其余模块按 import 图自动加载。模块间唯一的跨层状态走 `js/state.js`（`APP.currentCraft`、`APP.focusChar`、`APP.gWave`），避免反向依赖入口层。

## 资源说明

- `assets/standard/*.webp` 为左右拼接原图：运行时 `loader.js` 会把它中分裁剪，左半作正面、右半作背面，并叠加金框。
- 奖闪（镭射）与冷烫工艺不依赖额外扫描图：在普卡正面叠加程序化全息膜（`cards.js` 的 shader），背面使用程序化全息箔。新增 `assets/flash_prize/`、`assets/code_perm/` 扫描图后，把 `js/state.js` 的 `CRAFT_SCANS` 改为 `true` 即可启用完整工艺切换与「立绘」模式。
- 恶人卡原图同样是左右拼接（左半人像、右半卡背），与英雄卡走完全一致的裁剪流程。

## 交互

- 点击卡牌飞近鉴赏；右键 / 双击翻面；鉴赏中左右滑动或键盘 ←/→ 切换
- 拖动空白处环视；滚轮/双指缩放；ESC 返回
- 键 `1/2/3` 切换展厅（恶人密室内锁定）；`R` 或底部按钮触发「星穹洗牌」
- 连点石碑光球 3 次解锁恶人密室（点击右下角进入），密室是独立场景，进入后不可切换展厅

## 冒烟测试

先起服务（`python serve.py 8123`），另开终端：

```bash
node tools/smoke.mjs
```

依次验证布局切换、洗牌、恶人密室进出，并输出各阶段截图到临时目录。
